Digit Classification Lab Work

This project shows how handwritten digit recognition is performed using the Scikit-learn digits dataset. It contains:

    1. Data loading and visualization
    2. Image preprocessing and flattening
    3. Training a Support Vector Machine (SVM) classifier
    4. Hyperparameter tuning with GridSearchCV
    5. Debugging using Python's built-in pdb
    6. Performance evaluation with classification report and confusion matrix
